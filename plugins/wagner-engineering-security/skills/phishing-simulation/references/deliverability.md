# Deliverability

Configure SPF, DKIM e DMARC de forma coerente com o domínio autorizado. Verifique alinhamento, reputação, DNS e headers.
Use infraestrutura separada quando apropriado para não comprometer reputação de domínio transacional.

Faça testes controlados antes da campanha e registre mensagens aceitas/rejeitadas, códigos SMTP e motivos de bloqueio.
