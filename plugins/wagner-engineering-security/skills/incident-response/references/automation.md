# Automação de IR

Automatize tarefas determinísticas: enrichment, dedupe, lookup, criação de timeline, coleta de artefatos,
notificação e preparação de ações. Para containment automático, exija confiança, idempotência, escopo limitado,
timeout, rollback/compensation quando possível e audit trail.

Cada step automatizado deve registrar input, decisão, output, erro e correlation ID.
