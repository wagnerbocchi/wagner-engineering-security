# Framework de avaliação

## Problema
- cliente específico;
- dor/frequência/custo atual;
- workaround/substituto;
- evidência observada.

## Adoção/economia
- quem decide/usa/paga;
- alternativa atual e custo;
- evidência de compromisso: pré-venda, LOI qualificada, piloto, budget, mudança de comportamento;
- para não-comerciais: impacto mensurável, sponsor e willingness to adopt.

## Experimentos
Priorize testes que podem falsificar a hipótese mais arriscada rapidamente.
